# Nectar Points Bank

A prototype for a potential new Nectar feature that allows customers to track their loyalty points towards physical products.

## Overview

This project demonstrates a new way for Nectar customers to visualize their progress towards redeeming physical products from Argos using their loyalty points. Instead of just seeing a generic points balance, users can track their points towards specific items they want.

## Features

- Points tracking widget showing progress towards specific products
- Prototype Argos product page integration showing the tracking widget
- Visual representation of points accumulation towards desired items
- Demonstration of how this feature could enhance the Nectar loyalty experience
